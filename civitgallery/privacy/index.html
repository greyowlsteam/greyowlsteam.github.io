Конфиденциальность CivitGallery

Без рекламы, аналитики и трекеров. Для просмотра аккаунт не нужен.

Только на телефоне

Тема, размер плиток и фильтры ленты, кэш картинок и карт глубины, токены входа (зашифрованы ключом в Android Keystore). Данные приложения не попадают в резервные копии Android.

Civitai

Картинки и данные о них загружаются напрямую с civitai.com. Вход через Civitai происходит на странице самого Civitai — пароль через приложение не проходит. После входа ваши реакции, коллекции, подписки и скрытые теги читаются и меняются в вашем аккаунте Civitai, по правилам конфиденциальности Civitai.

Наш сервер (расширенные теги)

После принятия правил приложение создаёт гостевой профиль, в нём:

  • ключ устройства — только открытая часть; закрытый ключ создаётся в Android Keystore и не покидает телефон;
  • название модели телефона и язык интерфейса;
  • подтверждение возраста и согласия на контент — с версией правил и датой;
  • случайный ник (user-123456), его можно сменить;
  • добавленные вами теги, голоса и жалобы, а также ID картинок Civitai, к которым они относятся;
  • если вы скрываете расширенные теги — ID этих тегов и картинок страницы ленты, чтобы найти, какие картинки скрыть или размыть;
  • настройки приложения: скрытые теги и авторы, скрываемые расширенные теги, рейтинги, согласия и звук видео — чтобы они вернулись после переустановки;
  • только если вы их привяжете: почта (код входа приходит письмом, хранится только хэш кода) и ID, имя пользователя и имя в Telegram.

Как любой веб-сервер, он сохраняет технические журналы запросов (время, адрес запроса, IP-адрес) для работы и защиты от злоупотреблений.

GitHub

Раз в сутки приложение спрашивает у GitHub последнюю версию, а модели глубины скачиваются с GitHub по кнопке. Личные данные не передаются, GitHub видит ваш IP-адрес.

Удаление данных

«Настройки → Профиль приложения → Удалить профиль» удаляет голоса, жалобы, способы входа, ключи устройств и сохранённые настройки. Добавленные теги остаются на картинках без вашего имени. Чтобы удалить данные с телефона, удалите приложение. Отключить Civitai — выйти из аккаунта в «Настройки → Аккаунт Civitai».
